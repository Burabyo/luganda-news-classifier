About this model

Test set (223 Luganda articles): this model reaches 89.2% accuracy and 87.3 macro-F1; the same configuration averages 90.9% accuracy and 89.2 macro-F1 over 3 seeds, against 88.5 macro-F1 for the best TF-IDF baseline. Model: Burabyo/luganda-news-afroxlmr (8-bit ONNX in the browser). Code, experiments and report: github.com/Burabyo/luganda-news-classifier.

Limitations: trained on 771 articles from one news site (Gambuuze); only five topics, so text about anything else is still forced into one of them; inputs are truncated to 256 subword tokens; confidence scores tend to be too high.

Data: MasakhaNEWS (Adelani et al., 2023). Base model: AfroXLMR-base (Alabi et al., 2022). Runtime: Transformers.js / ONNX Runtime Web.
